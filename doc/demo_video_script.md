# Demo Video Script (3 นาที) — ThaiLaw Assistant

บันทึกหน้าจอ LINE (มือถือหรือ emulator) + เสียงบรรยาย ตามลำดับนี้ สำรองไว้กันเน็ต/LINE ล่มตอนนำเสนอจริง

## Storyboard

| เวลา | ฉาก | บรรยาย (พูด) | สิ่งที่โชว์บนจอ |
|---|---|---|---|
| 0:00–0:20 | เปิด | "ThaiLaw Assistant คือผู้ช่วยตอบคำถามกฎหมายแรงงานไทย ผสาน Dense retrieval, Graph retrieval และ LLM เข้าด้วยกันแบบ Hybrid RAG บน LINE" | Title card / architecture diagram จาก `doc/report.md` |
| 0:20–0:50 | คำถามพื้นฐาน (single-hop) | "ลองถามคำถามสิทธิพื้นฐาน" | พิมพ์ "ลาป่วยได้กี่วันโดยได้ค่าจ้าง" → โชว์คำตอบพร้อมอ้างอิงมาตรา + Flex card |
