# ผู้ช่วยกฎหมายไทยสำหรับประชาชนด้วย GraphRAG

## ชื่อโครงงาน

**ThaiLaw Assistant: ระบบผู้ช่วยตอบคำถามกฎหมายไทยด้วย GraphRAG และ LLM**

## ที่มาและความสำคัญ

ประชาชนทั่วไปมักค้นหากฎหมายจากเอกสารจำนวนมากและใช้ภาษากฎหมายที่เข้าใจยาก ระบบนี้ช่วยค้นหาและอธิบายกฎหมายไทยด้วยภาษาธรรมชาติ พร้อมแสดงมาตราและแหล่งอ้างอิงต้นฉบับ

GraphRAG เหมาะกับหัวข้อนี้ เพราะกฎหมายมีความสัมพันธ์หลายชั้น เช่น กฎหมาย มาตรา นิยาม สิทธิ หน้าที่ บทลงโทษ และหน่วยงานที่เกี่ยวข้อง

## วัตถุประสงค์

1. พัฒนาระบบสนทนาสำหรับตอบคำถามกฎหมายไทย
2. เชื่อมโยงข้อมูลกฎหมายด้วย Knowledge Graph
3. สรุปสิทธิ หน้าที่ และขั้นตอนดำเนินการให้เข้าใจง่าย
4. แสดงแหล่งอ้างอิงเพื่อให้ตรวจสอบคำตอบได้
5. ลดปัญหาการตอบข้อมูลโดยไม่มีหลักฐานอ้างอิง

## กลุ่มผู้ใช้

- ประชาชนทั่วไป
- นักเรียนและนักศึกษา
- ผู้ประกอบการรายย่อย
- ผู้ที่ต้องการค้นหาข้อมูลกฎหมายเบื้องต้น

## ขอบเขตระบบระยะเริ่มต้น

- กฎหมายแรงงาน
- กฎหมายคุ้มครองผู้บริโภค
- กฎหมายธุรกิจขนาดเล็ก
- กฎหมายจราจร
- กฎหมายเช่าที่พัก

## ความสามารถหลัก

- รับคำถามกฎหมายด้วยภาษาธรรมชาติ
- ค้นหามาตราและเอกสารที่เกี่ยวข้อง
- สรุปเนื้อหากฎหมายเป็นภาษาที่เข้าใจง่าย
- แสดงสิทธิ หน้าที่ และบทลงโทษ
- แนะนำหน่วยงานที่เกี่ยวข้อง
- แนะนำเอกสารหรือหลักฐานที่ควรเตรียม
- แสดงลิงก์อ้างอิงต้นฉบับ
- แจ้งเตือนว่าข้อมูลเป็นคำแนะนำเบื้องต้น ไม่ใช่คำปรึกษาจากทนายความ

## ตัวอย่างคำถาม

> นายจ้างไม่จ่ายค่าล่วงเวลา ต้องทำอย่างไร?

ระบบควรตอบข้อมูลต่อไปนี้:

1. สิทธิของลูกจ้าง
2. มาตรากฎหมายที่เกี่ยวข้อง
3. หลักฐานที่ควรเก็บ
4. หน่วยงานที่สามารถร้องเรียน
5. ขั้นตอนดำเนินการ
6. แหล่งอ้างอิงต้นฉบับ

## โครงสร้าง Knowledge Graph

```text
กฎหมาย
 ├─ มาตรา
 ├─ นิยาม
 ├─ สิทธิ
 ├─ หน้าที่
 ├─ บทลงโทษ
 ├─ หน่วยงาน
 ├─ แบบฟอร์ม
 └─ เอกสารที่เกี่ยวข้อง
```

ตัวอย่างความสัมพันธ์:

```text
กฎหมายแรงงาน
  └─ มีมาตรา → มาตราเกี่ยวกับค่าล่วงเวลา
       ├─ คุ้มครอง → ลูกจ้าง
       ├─ กำหนดหน้าที่ → นายจ้าง
       ├─ อ้างอิงโดย → กระทรวงแรงงาน
       └─ ใช้หลักฐาน → สัญญาจ้าง / สลิปเงินเดือน / บันทึกเวลา
```

## แนวทางการทำงานของระบบ

```text
ผู้ใช้ถามคำถาม
        ↓
แยกประเด็นและคำสำคัญ
        ↓
ค้นหาเอกสารและโหนดใน Knowledge Graph
        ↓
จัดอันดับมาตราและเอกสารที่เกี่ยวข้อง
        ↓
LLM สร้างคำตอบพร้อมแหล่งอ้างอิง
        ↓
แสดงคำตอบและคำเตือนการใช้งาน
```

## เทคโนโลยีที่เสนอ

- LLM สำหรับทำความเข้าใจคำถามและสร้างคำตอบ
- Embedding Model สำหรับค้นหาเอกสาร
- Vector Database สำหรับเก็บข้อมูลเวกเตอร์
- Graph Database เช่น Neo4j สำหรับ Knowledge Graph
- RAG และ GraphRAG สำหรับค้นคืนข้อมูล
- Web application หรือ LINE Chatbot สำหรับส่วนติดต่อผู้ใช้

## ขอบเขต MVP

- รองรับกฎหมายแรงงานเป็นโดเมนแรก
- นำเข้าเอกสารจากเว็บไซต์และ PDF ของหน่วยงานรัฐ
- สร้างกราฟกฎหมายอย่างน้อย 4 ประเภท ได้แก่ กฎหมาย มาตรา หน่วยงาน และสิทธิ
- ตอบคำถามภาษาไทยอย่างน้อย 20 กรณี
- แสดงคำตอบพร้อมมาตราและ URL อ้างอิง
- ทดสอบความถูกต้องกับชุดคำถามที่เตรียมไว้

## การประเมินผล

- ความถูกต้องของมาตราที่ค้นพบ
- ความครบถ้วนของแหล่งอ้างอิง
- ความถูกต้องของคำตอบ
- ความเข้าใจง่ายของภาษา
- เวลาในการตอบคำถาม
- ความพึงพอใจของผู้ทดลองใช้

## ข้อจำกัดและความปลอดภัย

- ระบบไม่ควรอ้างว่าเป็นทนายความ
- คำตอบต้องมีแหล่งอ้างอิงตรวจสอบได้
- ต้องระบุวันที่ปรับปรุงข้อมูลกฎหมาย
- กรณีซับซ้อนควรแนะนำให้ปรึกษาทนายความหรือหน่วยงานรัฐ
- ต้องระวังข้อมูลกฎหมายที่ถูกแก้ไขหรือยกเลิก

## ผลลัพธ์ที่คาดหวัง

ได้ระบบผู้ช่วยกฎหมายภาษาไทยที่ช่วยประชาชนค้นหาสิทธิและขั้นตอนเบื้องต้นได้เร็วขึ้น โดยใช้ GraphRAG เพื่อเชื่อมโยงข้อมูลกฎหมายและลดคำตอบที่ไม่มีหลักฐานอ้างอิง
